# 星谷创新工程中心管理系统接口文档

## 1. 接口概述

本接口文档描述了星谷创新工程中心管理系统的后端API接口，主要包括用户认证、学生信息管理和移动端报名相关功能。

### 1.1 基础信息

- **API基础路径**: `/api`
- **请求方法**: GET, POST, DELETE
- **响应格式**: JSON
- **认证方式**: JWT Token
- **状态码**: 200(成功), 400(请求错误), 401(未授权), 500(服务器错误)

## 2. 认证接口

### 2.1 登录接口

**接口地址**: `/api/auth/login`

**请求方法**: POST

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| username | string | 是 | 管理员用户名 |
| password | string | 是 | 管理员密码 |

**请求示例**:
```json
{
  "username": "json",
  "password": "666666"
}
```

**响应示例**:

**成功**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "json",
      "role": "admin"
    }
  }
}
```

**失败**:
```json
{
  "code": 401,
  "message": "账户或密码错误"
}
```

### 2.2 登出接口

**接口地址**: `/api/auth/logout`

**请求方法**: POST

**请求头**:
| 字段名 | 值 |
|-------|------|
| Authorization | Bearer {token} |

**响应示例**:
```json
{
  "code": 200,
  "message": "登出成功"
}
```

## 3. 学生信息管理接口

### 3.2 删除学生

**接口地址**: `/api/students`

**请求方法**: DELETE

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| ids | array | 是 | 学生ID数组 |

**请求头**:
| 字段名 | 值 |
|-------|------|
| Authorization | Bearer {token} |

**请求示例**:
```json
{
  "ids": ["23360911", "23360913"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "删除成功",
  "data": {
    "deleted": 2
  }
}
```

## 4. 移动端报名接口

### 4.1 移动端报名

**接口地址**: `/api/students/register`

**请求方法**: POST

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| id | string | 是 | 学号 |
| name | string | 是 | 姓名 |
| major | string | 是 | 专业 |
| grade | string | 是 | 年级 |
| qq | string | 是 | QQ号 |
| phone | string | 是 | 电话 |

**请求示例**:
```json
{
  "id": "23360915",
  "name": "小刘",
  "major": "人工智能",
  "grade": "2024",
  "qq": "987654321",
  "phone": "987654321"
}
```

**响应示例**:

**成功**:
```json
{
  "code": 200,
  "message": "报名成功",
  "data": {
    "id": "23360915",
    "name": "小刘",
    "redirectUrl": "http://localhost:3000/#/"
  }
}
```

**失败**:
```json
{
  "code": 400,
  "message": "报名失败，学号已存在"
}
```

### 4.2 移动端报名状态查询

**接口地址**: `/api/students/register/status`

**请求方法**: GET

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| id | string | 是 | 学号 |

**响应示例**:
```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "status": "registered", // registered: 已报名, not_registered: 未报名
    "student": {
      "id": "23360911",
      "name": "小李",
      "major": "软件工程",
      "grade": "2023"
    }
  }
}
```

## 5. 数据模型

### 5.1 学生信息

| 字段名 | 类型 | 描述 |
|-------|------|------|
| id | string | 学号(主键) |
| name | string | 姓名 |
| major | string | 专业 |
| grade | string | 年级 |
| qq | string | QQ号 |
| phone | string | 电话 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

### 5.2 管理员信息

| 字段名 | 类型 | 描述 |
|-------|------|------|
| id | number | 管理员ID |
| username | string | 用户名 |
| password | string | 密码(加密存储) |
| role | string | 角色 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

## 6. 错误码说明

| 错误码 | 描述 |
|-------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权或登录失败 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 7. 开发建议

1. **前端实现**:
   - 使用 axios 进行API调用
   - 统一处理响应和错误
   - 使用 localStorage 存储 token

2. **后端实现**:
   - 使用 Express 或 Koa 构建API
   - 使用 JWT 进行身份验证
   - 使用 Sequelize 或 Mongoose 操作数据库
   - 实现 CORS 跨域支持

3. **安全性**:
   - 密码加密存储
   - API请求验证
   - 防止SQL注入
   - 限流保护
